## 🚀 Overview

**OMNI-TECH-HUB** is a dual-purpose repository housing:
1. **The OMNI-TECH-HUB Portfolio Web Matrix** — A terminal-inspired, credential-gated engineering portfolio featuring live PDF/video project showcases, dynamic JSON data management, and dark/light cyber-blue themes.
2. **Arduino Cybersecurity Rover (`rover_core.ino`)** — Hardware firmware, telemetry loops, and 3D-printable structural designs for an autonomous/remote security rover.

---

## 🛠️ Key Features

### 🌐 Web Portfolio Matrix
* **Terminal Boot Preloader & Security Gate:** Simulated kernel boot sequence protected by client-side token authentication (`Alpha-codes`).
* **Dynamic Content Controller (`admin.html` & `data.json`):** Manage skills, M-Pesa service rates, social channels, and downloadable credentials without editing raw HTML.
* **Live Media Showcase:** Built-in upload and preview support for engineering **PDF schematics** and **video demonstrations**.
* **Adaptive Cyber-Carbon UI:** Smooth switching between default Cyber-Blue Dark Mode and Clean Light Mode.

### 🤖 Hardware & Mechatronics (`rover_core.ino`)
* Microcontroller sensor polling and real-time fault telemetry.
* Modular actuator control and rapid-prototyped 3D CAD enclosures.

## 💻 Local Setup & Deployment

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd omni-tech-hub
   ```
2. **Run locally:**
   Open `index.html` directly in your browser or serve with any static server (e.g., `python3 -m http.server 8080`).
3. **Access Token:**
   Use **`Alpha-codes`** at the login gate to unlock the workspace.
